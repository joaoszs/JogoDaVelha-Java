# 🎮 Jogo da Velha — Java

Projeto de **Jogo da Velha desenvolvido em Java**, utilizando **Java Swing**, **matrizes**, **Programação Orientada a Objetos (POO)** e **integração com banco de dados**.

## 🎯 Objetivo

Projeto desenvolvido para praticar e consolidar conhecimentos de Java através da construção de uma aplicação desktop completa, combinando lógica de jogo, interface gráfica e persistência de dados.

## 🧠 Conceitos praticados

* ☕ Java
* 🧱 Programação Orientada a Objetos (POO)
* 🖥️ Java Swing
* 🔢 Matrizes
* 🗄️ Integração com banco de dados
* 🔄 Manipulação e persistência de dados
* 🎮 Lógica e regras do jogo

## ⚙️ Funcionalidades

* 🎮 Jogo da Velha através de interface gráfica
* 👥 Interação entre jogadores
* 🏆 Verificação de vitória e empate
* 🔢 Controle do tabuleiro através de matriz
* 🗄️ Integração com banco de dados

## 🛠️ Tecnologias

* Java
* Java Swing
* Banco de dados relacional

## ▶️ Execução

Clone o repositório e abra o projeto em uma IDE compatível com Java.

Configure a conexão com o banco de dados de acordo com as configurações utilizadas no projeto e execute a classe principal da aplicação.
